# Communication

All that's left is to implement communication.

I won't give too much guidance on this, but I will recap the brief:

An employee can log a communication between themselves and one of the organisations they manage. The communication can be either inbound or outbound in nature, and by either phone or email. If logging an inbound communication with a point of contact not in the system, the user can include this in their request and it will create them in the database on a provisional basis- with only the manager being able to promote them to a permanent point of contact.
