# Implementing Auth

This is a shorter and less theoretical section, but an important one because it's more freeform in nature. Guidance will be limited, and will require you thinking about your prompt to get this done correctly.

Git is your friend if something goes wrong, so remember to keep good Git hygiene.

Things to remember about Auth from our brief

1. API Key Authentication
2. Multiple permissions available (Reader, Contributor, Manager, Admin)
3. Only API keys set to admin level can create and manage API keys

Ensure that your prompt ONLY creates the auth code required and doesn't proceed with any other functionality - this is about controlling your agent properly via prompting.

Once you have done this successfully, proceed to the next section.
