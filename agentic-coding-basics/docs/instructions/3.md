# Adding employees

Now it's time to implement employees into our application. This requires a few steps

- defining the model
- crud operations
- setting permissions

This workflow will be followed for other database entities when we add them, so now is a good time to create a skill.

A skill is a format for adding specialised knowledge and workflows to an agent in a lightweight way.

For example, we are about to create a skill called `add-crud`, that will handle the tasks above to ensure that similar operations are implemented in a consistent way.

To do this, create the following file: `.agents/skills/add-crud/SKILL.md`

Populate it with the following:

```
---
name: add-crud
description: Follows a structured process for adding a new database entity and related crud operations
---

To add a new entity to the database, follow these steps:

1. Define the entity by asking the user probing questions
2. Create the entity
3. Add database migration
4. Create HTTP resources for managing the entity
5. Apply permissions to the endpoints as follows:
  a. CREATE/DELETE: Admin
  b. UPDATE: Manager
  c. READ: Reader and above
```

Now, begin a new session and write a prompt to add the Employee entity. At this point an employee will have a first and last name, email address and a manager.

Once complete we should have our first CRUD operations working.
