# Workshops

A collection of DIY workshops following the "Workshop in a Box" methodology.

## What is Workshop in a Box?

Workshop in a Box is an open-source format for sharing focused workshops, enabling anyone to pick up and deliver them.

- Complete, self-contained workshop material in a shareable format
- Open-source structure removes barriers to accessing and sharing knowledge
- Anyone can pick it up and facilitate without modification or special training
- Designed for hands-on, practical skill-building
- Emphasis on reproducibility and accessibility
