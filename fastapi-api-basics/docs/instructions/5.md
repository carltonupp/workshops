# Testing and quality

pytest is the de facto test runner and httpx the client library. FastAPI ships a `TestClient` that exercises your ASGI app entirely in-process - functionally the `WebApplicationFactory` of this ecosystem: no server, no ports, full middleware stack.

```
uv add --dev pytest httpx
```

The idiom to internalise: endpoints receive their session via `Depends`, so tests override that registration rather than monkeypatching modules - the same instinct as swapping a DI service in a test host:

```python
from fastapi.testclient import TestClient
from sqlmodel import Session, SQLModel, create_engine
from main import app, get_session


def make_client() -> TestClient:
    engine = create_engine("sqlite://", connect_args={"check_same_thread": False})
    SQLModel.metadata.create_all(engine)

    def override():
        with Session(engine) as session:
            yield session

    app.dependency_overrides[get_session] = override
    return TestClient(app)


def test_create_then_get():
    client = make_client()
    response = client.post("/tasks", json={"title": "Write tests"})
    assert response.status_code == 201
    assert client.get(f"/tasks/{response.json()['id']}").json()["title"] == "Write tests"


def test_missing_task_is_404():
    assert make_client().get("/tasks/999").status_code == 404
```

Run it with `uv run pytest`. Then convert each rule from the brief into a test: past due date rejected, done task refused when moved back to todo. Decide deliberately whether business-rule rejections are 422 or 409 on this API - whichever you choose, the tests are how that decision gets published.

For tooling, ruff has consolidated flake8, black, isort and pyupgrade into one linter/formatter configured in `pyproject.toml`:

```
uv add --dev ruff
uv run ruff check --fix .
uv run ruff format .
```

If you want static typing beyond what Pydantic enforces at the boundaries, basedpyright or mypy slots in cleanly. Adopt what you want now and wire it into CI while the codebase is still small enough to fix in one sitting.
