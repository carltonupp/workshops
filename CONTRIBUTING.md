# Contributing to Workshops

Thank you for your interest in contributing! This repository contains my curated collection of Workshop in a Box workshops.

## About This Repository

This is a **curated collection**, not a community-driven project. While Workshop in a Box is an open-source format anyone can adopt and adapt, **this specific repository is for my own workshops**.

Contributions should be improvements, feedback, or bug fixes to existing workshops—not submissions of new workshops.

## What We Welcome

- **Bug reports** – typos, broken steps, outdated dependencies, unclear instructions
- **Feedback** – suggestions to improve clarity, accessibility, or pedagogy
- **Documentation improvements** – better explanations, additional examples, clearer progression
- **Testing & validation** – running workshops and reporting what worked or didn't
- **Accessibility improvements** – making workshops more inclusive

## What We Don't Accept

- New workshop submissions (create your own Workshop in a Box repository instead)
- Major structural changes to existing workshops
- New tools, frameworks, or languages in established workshops

## How to Contribute

### Reporting Issues

Open a GitHub issue with:
- What workshop and step it relates to
- What went wrong (error message, unclear instruction, etc.)
- Your environment (OS, tool versions, etc.)
- Steps to reproduce

### Suggesting Improvements

Open a discussion or issue with:
- What you'd like to improve and why
- Specific suggestions if you have them
- Context on where this would help (solo learners, facilitators, etc.)

### Submitting a Pull Request

1. Fork the repository
2. Create a branch (`git checkout -b fix/workshop-name-issue`)
3. Make your changes
4. Test your changes (ideally by running the workshop)
5. Commit with a clear message
6. Open a pull request describing what you fixed or improved

**Keep PRs focused** – one fix or improvement per PR is easier to review.

## Code of Conduct

Be respectful, constructive, and collaborative. We're here to improve workshops for learners and facilitators.

## Creating Your Own Workshops

If you'd like to create your own Workshop in a Box, you're encouraged to do so! Fork this repository or start fresh—the format is designed to be adopted and adapted.

Share your work, and let's build better learning experiences together.

---

Have questions? Open a discussion or issue, and we'll help.
